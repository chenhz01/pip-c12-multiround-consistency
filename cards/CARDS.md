# Learning Cards

Each card has four layers: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Plus the gap evidence.

---

## 多轮一致

> 同一件事问三遍，三个答案，而且都说自己对。

### L45 · 多轮一致性

`cross-pass-consistency` · `components/L45-cross-pass-consistency/`

- **L0（人话）** 同样的问题问三次，答案要素要是差太多，说明它其实没想清楚，只是每次说得都挺像。
- **L1（本质）** 两两 Jaccard，报最小值/均值/最大值。关键：可信度看最小对，均值会掩盖分歧——两个 0.9 和一个 0.1 的平均值仍然好看。
- **L2（怎么用）** 重要判断跑 3 次；最小对 <0.35 判不一致，回去补规格而不是再问一次。
- **边界** 要素集合需先定义；要素划分不同则结果不可比。
- **空白证据** 自一致性采样（self-consistency）测最终答案，缺「跨轮要素一致性」的判定（抽样未单列）。

### L46 · 矛盾登记册

`contradiction-registry` · `components/L46-contradiction-registry/`

- **L0（人话）** 以前说 A，现在说 B，要写清楚为什么改。不写的话，过两周又会有人说回 A。
- **L1（本质）** 只登记不删除：被推翻的结论保留「谁推翻、为什么、何时」。同主题不同立场且无 supersedes 关系 → 未解冲突，必须显式裁决。
- **L2（怎么用）** 每次改结论登记一条；出现 has-unresolved 就当场裁决，别靠「后来者自然覆盖」。
- **边界** 只登记显式矛盾；措辞不同但语义冲突的需人发现。
- **空白证据** 版本控制管文件差异，缺「结论级矛盾登记与裁决」的原语（抽样 2 命中）。

### L47 · 信念修订账本

`belief-revision-ledger` · `components/L47-belief-revision-ledger/`

- **L0（人话）** 看到一点像证据的东西，就以为自己被证实了——其实还要看「这种证据平时多容易误报」。
- **L1（本质）** 简化贝叶斯：后验 ∝ 先验×似然，分母加上 (1−先验)×误报率。它让「看起来像证据」的东西在误报率高时涨不动。账本必须留先验、似然、证据三件。
- **L2（怎么用）** 每次更新记录三元组；只记后验不记先验的账本，事后无法复核。
- **边界** 似然与误报率要外部给；给错则后验更不可信。
- **空白证据** 贝叶斯工具很多，缺「带误报率、面向结论修订」的轻账本（抽样 2 命中）。
